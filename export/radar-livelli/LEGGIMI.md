# Esportazione della sezione "Livelli" verso radar

| File | Contenuto |
|---|---|
| `PROMPT.md` | il prompt da incollare nella sessione Claude Code di radar |
| `livelli.py` | modulo autonomo che calcola livelli e zone (`python livelli.py btc_giornaliero.csv` per provarlo) |
| `oggi.json` | uscita del modulo sui dati al 23/11/2026, con le liquidazioni di Coinglass del 24/11/2026 |
| `btc_giornaliero.csv` | giornaliero BTC dal 2017 (Bitstamp fino al 17/08/2017, poi Binance spot) |
| `rotture.csv` | tutte le rotture di supporti e resistenze dal 2018 usate nello studio |
| `LIVELLI_BTC.md` | lo studio completo |
| `anteprima_desktop.png`, `anteprima_telefono.png` | come appare la sezione nello strumento |
| `riferimento_pagina.html` | la pagina dello strumento (funzione `oggi()`), come riferimento per layout e colori |
